# 0.2.0-rc.5 完整源码审查

范围为全部自有生产 Kotlin 与 Swift 实现、平台采集入口、文件流/归档与通知链路；不把厂商实现或生成源码记为本库审查。共 30 个生产文件，逐文件清单与 SHA 留在本轮 `build/full-review/coverage.json`。

## 修复

- OHOS 可选通知模块新增 Curl transport；RFC 2104 HMAC 复用同仓库 SHA-256，避免提高 API 12 基线。共 14 个 Maven publication，core 不依赖通知模块。
- HTTP 成功响应按 16 KiB 字节限长，多字节文本不会绕过限制；`errcode` 只接受整数 JSON 字面量。
- 文件读取在 I/O 校验边界拒绝负快照大小，不改变 Swift 构造器的异常 ABI。

## 回归与边界

Android/JVM 的 core 与通知测试均通过；测试包含 RFC 4231 长/短密钥向量、复用摘要算法与 JCA 对照、多字节响应、非法类型和文件读取边界。测试只用 MockEngine，不投递真实通知。

本轮 core/通知模块 iOS Simulator 测试和 OHOS 通知模块编译均通过（native-tests.log）。完整14模块发布归档及最终staging消费者链接通过；当时尚未发布；当前不可变发布与精确远程文件核验结果见下文，Maven最终消费现已通过，见文末。Swift 原生采集源码未变，继续配套 rc.1。系统真实报告递送、后台退出和业务上传由设备验收确认。
