# 0.2.0-rc.11 冻结发布候选

rc.11 首次发布 `diagnostics-ktor` 的 `DiagnosticStore.openFileChannel` / `DiagnosticFileChannel`，由上传 scope 持有流，提供有界文件读取与 EOF/close 屏障。读取成功不自动确认批次；上传失败或取消仍由宿主保留/重试并显式确认原批次。生产代码来自 [PR #22](https://github.com/gycrosskit/diagnostics/pull/22)，合入 main `1f5c3abd2987a432f32037fa2b31864622706b60`。

- 归档来源 commit：`98c5aae8f16b1321a9626f5e23d2b36b1eee13bb`。
- 远程 macOS 归档：[run 38052715723](https://github.com/gycrosskit/diagnostics/actions/runs/38052715723)。
- `diagnostics-maven.tar.gz` SHA-256：`6970627a74f5d824ad5b1decc359fe5352d9bbd842cb4636a964e3b53877e43d`。
- 四模块完整 24 个 Maven publication，iOS arm64/x64/simulator arm64、OHOS arm64、JVM/Android；全部 POM/license/变体/内部版本与四种产物/sidecar 哈希通过，JVM/AAR major ≤61。
- 原始归档、SHA256SUMS 与 `provenance.json` 作为 Release 资产保留；provenance 的 59 个生产/测试/构建输入逐文件 hash 已核对。发布 tag 仅增加 checksum/文档冻结，不重新构建归档。

公开 JitPack inventory 与独立消费者必须在 [Release](https://github.com/gycrosskit/diagnostics/releases/tag/0.2.0-rc.11) 发布后分别成功；该发布准备记录不代替其执行回执。消费者直接引用新 API，在 JVM/Android unit/iOS Simulator 实读临时文件并确认关闭与批次保留；iOS Framework/OHOS sharedLib 编译该调用。

兼容组合为 Maven rc.11 + 独立 Swift Package/Git Pod rc.1。原生 support 未变，没有新 HAR/OHPM。未验证系统真实采集/业务上传/磁盘满/kill 或设备行为；宿主接线由固定新版本的宿主 PR 验收。
