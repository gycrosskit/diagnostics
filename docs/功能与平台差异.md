## Core、可选模块与消费入口

| 实际模块 / 包 | 职责 |
| --- | --- |
| `diagnostics-core` / `io.github.gycrosskit.diagnostics` | 有界日志、报告、稳定批次、逐文件读取与 TAR；平台 factory、Android/OHOS 采集、iOS 中性报告解析 |
| `diagnostics-ktor` / `io.github.gycrosskit.diagnostics.ktor` | 可选 Ktor 网络诊断插件；Android/iOS/JVM/OHOS engine 由平台提供 |
| `diagnostics-okhttp` / `io.github.gycrosskit.diagnostics.okhttp` | Android/JVM 可选 OkHttp interceptor，无 iOS/OHOS 变体 |
| `diagnostics-dingtalk` / `io.github.gycrosskit.diagnostics.dingtalk` | 显式调用的 webhook、签名与发送；不自动上传 |
| `GYDiagnosticsNative` / [ios-support](../ios-support/GYDiagnosticCollector.swift) | 独立 Swift Package / Git Pod；MetricKit 与 NSException，不能由 Maven 依赖自动安装 |

构建模块见 [settings](../settings.gradle.kts)。没有 `diagnostics-cmp`、`diagnostics-kuikly` 或 ArkTS HAR 桥；CMP/Kuikly 是基础设施的消费方。

| 五种入口 | 实际映射 | 宿主接线 |
| --- | --- | --- |
| CMP Android | Core Android + 按需 Ktor/OkHttp/DingTalk | Application 准入与采集器生命周期；不在每次重组安装 |
| CMP iOS | Core Native + Ktor/DingTalk；Swift 包独立接入 | Swift 回调转交 store，应用持有采集实例 |
| Kuikly Android | 与 CMP Android 相同 Core | 原生宿主共享同一实例，页面仅观察结果 |
| Kuikly iOS | 与 CMP iOS 相同 Core/Swift 包 | 由原生宿主接线，无 Kuikly 专有采集器 |
| Kuikly OHOS | Core OHOS + Ktor/DingTalk | Kotlin/Native 宿主传专属目录；ArkTS 调用需宿主已有 FFI，库未提供现成桥 |

| [AndroidNativeCrashCollector](../diagnostics-core/src/androidMain/kotlin/io/github/gycrosskit/diagnostics/AndroidNativeCrashCollector.kt) | 显式 start；API30+ `REASON_CRASH_NATIVE` 退出元数据，API31+ 系统尚保留的 tombstone protobuf 有界 Base64 原文 | 使用自身系统采集 | 使用自身系统采集 |

| [OhosCrashRecorder](../diagnostics-core/src/ohosArm64Main/kotlin/io/github/gycrosskit/diagnostics/OhosCrashRecorder.kt) | 无此入口 | 无此入口 | HiAppEvent API12+ APP_CRASH→CRASH、APP_FREEZE→HANG；系统延迟投递 |

默认 store：日志每卷5MiB、5卷；报告512KiB、5份；批次20文件/60MiB。ANR 使用独立 `AnrReportStore`（10份/256KiB），Swift Collector 按三类各10份；这些留存策略不能互换。

## 差异分类与生命周期

- **组件范围/不提供的入口**：本库提供诊断基础设施，不提供 UI 页面或现成 OHOS ArkTS 桥；这些范围边界不代表待新增模块。
- **待补齐覆盖**：Android24–29 尚无 native crash 采集覆盖，当前组件不能满足该系统范围的 native 诊断需求；API30+ 本版本仅补足部分系统历史能力，不能称三端 native crash 全覆盖或实时等价。旧系统没有 ApplicationExitInfo，替代采集方式需另行确定。
- **OS/SDK 限制**：Android API30 不读取 trace，避免把先前 ANR trace 当成 native protobuf；API31+ trace 可能已被系统覆盖且本库不解析 protobuf。iOS MetricKit、OHOS HiAppEvent 均可能延迟或不投递；NSException 不覆盖所有 Swift fatalError、signal、OOM/硬杀。
- **宿主职责**：隐私准入、脱敏、私有目录、单实例/单进程目录所有权、后台 I/O、通知/上传与确认。Store 锁只保证实例内串行；批次/reader 不跨实例，reader 独立关闭。
- **collector 合同**：每次最多16个 exit、192KiB trace，按 Store 目录保存最多64个组合身份；失败落盘不 mark。报告与 marker 分两次原子写入，进程退出或 marker 失败可能重导入。目录不强制 noBackup，建议用平台 factory。先 close collector 再 close store；native collector close 不等待无期限系统 trace，迟到数据丢弃并关闭流。ANR monitor 的 close 则同步等待已开始的采集，须后台调用。
- **未验收**：本轮未触发业务 App crash/freeze，未验证 Android Binder 真实历史递送、真机 MetricKit/HiAppEvent、磁盘满、跨进程或真实分享/网络通知。源码支持不能替代这些验收。
